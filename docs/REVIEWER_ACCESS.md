# Reviewer access

The hosted demo uses Basic Authentication. Reviewer credentials are supplied separately in the submission email; they are not stored in this repository.

## Access path

1. Open [the hosted demo](https://grocery.parkerwall-dev.workers.dev/).
2. Enter the temporary username and password from the submission email.
3. Confirm that the Grocery List upload screen loads.

The temporary credentials remain active for 14 calendar days after submission. After that window, I will rotate or remove them. If the review runs longer, I can issue a new temporary credential without changing the repository.

The Arize AX deep links point to a private workspace. The repository includes screenshots and a scrubbed experiment export so the product argument does not depend on workspace access.
